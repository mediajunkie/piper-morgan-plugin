# Eval results: does the bare connector reach Piper? (routing, 2026-10-15)

**Run**: 2026-10-15, Claude Code eval harness, `evals-routing/run.sh` (5 runs per case), then 10 more per bare case
(`results/run-2026-10-15b`). **105 runs, $9.67**, all complete (`partial: false`), 0 run errors. Grader:
`called-piper` only (did Claude call `what_piper_knows_about_me`). Mocked connector, post-#2005 payload.

**Why**: in the #2005 eval, "How many open GitHub issues do I have?" reached Piper 7 of 15 times through the bare
connector and 15 of 15 through the full plugin. xian's direction (10-14): smart server first, then connector, then
skills. So before writing a routing skill, this tests the cheapest server lever: the tool description.

| Description | Rewrite under test |
|---|---|
| current | the server's text (MCP v14): "Read-only. Returns what Piper Morgan knows about the signed-in user…" |
| usefirst | same facts, opening with the questions it answers: "Use this for questions about the signed-in user's own work: their open GitHub issues (how many, which ones, what to work on next), their projects and their priorities." |

## Results (called Piper / runs)

| Question | bare, current | bare, usefirst | full plugin, current |
|---|---|---|---|
| "How many open GitHub issues do I have?" | 8 / 15 | 9 / 15 | 5 / 5 |
| "What's assigned to me on GitHub right now?" | 10 / 15 | 13 / 15 | 5 / 5 |
| "What should I work on today?" | 15 / 15 | 15 / 15 | 5 / 5 |
| **All** | **33 / 45** | **37 / 45** | **15 / 15** |

## What it says

1. **The description rewrite doesn't fix routing.** The count question is 8 vs 9 of 15, which is noise. The
   "assigned to me" gain (10 → 13) is within what 15 runs can't distinguish from chance. Not worth shipping on
   this evidence.
2. **Bare routing fails on GitHub-named questions, not on work questions.** "What should I work on today?" reached
   Piper 30 of 30 times without the plugin. The misses are questions that say "GitHub", where Claude has another
   route in mind (on 10-14, `gh` and a subagent; this run's traces weren't kept, so 10-15's misses weren't read).
3. **The plugin still routes perfectly** (15 of 15 here; 15 of 15 on the count question on 10-14).

## Limits

- Claude Code harness. Its agent knows `gh` exists; Claude Desktop and ChatGPT may route differently. The real
  test is PM asking in Desktop.
- Untested server levers: the tool name (`what_piper_knows_about_me` doesn't say "GitHub"), and an MCP server
  `instructions` string (the server sets none; this mock harness can't carry one).
- 15 runs per bare cell, 5 per plugin cell.
